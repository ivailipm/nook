# nook: design handoff

| File | What it is |
| --- | --- |
| `PROMPT.md` | The prompt to paste into Claude Code |
| `DESIGN.md` | Visual spec: fonts, colours, components, layout |
| `FEATURES.md` | Behaviour spec: every screen, data model, parsing rules, notifications, PWA |
| `prototype/Main.dc.html` | Source of the clickable prototype (reference only, canvas format: read, don't run) |
| `prototype/Mobile.dc.html` | Mounts the same prototype at phone size |
| `reference/look-and-feel.png` | The mood reference for the look |

Put this folder in the root of the new repo (e.g. `docs/nook-design/`, then fix the folder name in the prompt), open Claude Code there, and paste the prompt from `PROMPT.md`.
